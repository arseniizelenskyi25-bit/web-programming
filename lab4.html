Теоретичні відомості

1. Пошук елементів в DOM

Для пошуку HTML-елементів на сторінці в JavaScript використовуються такі основні методи:

  • document.getElementById('id') — знаходить елемент за його унікальним ідентифікатором ID.
  • document.getElementsByName('name') — повертає колекцію елементів з відповідним атрибутом name.
  • document.querySelector('selector') — повертає перший елемент, який відповідає CSS-селектору.
  • document.querySelectorAll('selector') — повертає всі елементи у вигляді статичної колекції NodeList.

2. Опрацювання елементів форми

Елементи форм дозволяють зчитувати значення, введені користувачем:

  • Для **радіокнопок (radio)** та **прапорців (checkbox)** перевіряється властивість checked.
  • Для **випадаючих списків (select)** зчитується властивість value або обходяться вибрані елементи option.selected.
  • Для **текстових полів (input type="text")** значення зчитується через властивість value.
